What is it called, and what is it for?

The name is the filename and the pin value. “What it’s for” is the line that makes this theme easy to choose later — write it for someone deciding between three options in a hurry.

02

Type

Three roles. Search any family on Google Fonts — it is the only font host a published artifact can load, so the list is deliberately limited to it. The fallback stack below each is what pages that cannot load a webfont get; it is pre-filled to keep the theme’s character, and you can change it.

03

Colour

Pick a ground and an accent. Everything else is derived to hit real contrast ratios in both schemes — the dark accent is lightened rather than reused, which is the usual way a hand-built dark palette goes wrong. Override any single token below if you disagree.

The page background. Its hue tints every neutral.

04

Shape & scale

How separate things look, and how far apart the type sizes sit. A wide measure with a tight ratio reads as reference; a narrow measure with a dramatic ratio reads as a poster.

05

Voice

This is the half of a theme that is not CSS. It is injected into every session, so it changes how Claude writes under this theme, not only how the page looks. Without it, picking a theme just repaints the same document.
