# What's in here

This repo is a personal toolkit for Claude Code: a set of plugins that carry aj's own working
rules and habits so they follow along on any machine, plus the scripts that install and check
them.

The documentation below is organized into six numbered folders, one per stage of the story — from
what this project is, through what's planned, where it stands, how it works, what's happening
today, and why past decisions were made:

- **[1-landing](1-landing/README.md)** — the full index: what's here, and where to find it.
- **[2-roadmap](2-roadmap/Roadmap.md)** — what "done" looks like, milestone by milestone.
- **[3-state](3-state/ProjectState.md)** — where things actually stand right now.
- **[4-systems](4-systems/README.md)** — how each important piece works.
- **[5-today](5-today/Today.md)** — what's being worked on today, and why.
- **[6-decisions](6-decisions/Decisions.md)** — the paper trail: what was decided, and why.

For the full picture, start at [1-landing/README.md](1-landing/README.md).
