# Reference page

`learning-tools-plugin.html` is aj's reference for what every handover page should look like. It was chosen on 2026-10-17.

What makes it the reference:

- **A picture for every item.** Each item in the overview and each item in the Changes section carries a picture showing what it creates: a folder tree, a step flow with its loop, a stable-versus-draft outline, an install path, a progress list, and the documentation tiers. aj wants pictures like these to become mandatory.
- **Pictures follow the theme.** The SVGs carry their own light and dark colours, so they read on either page background.
- **Text matches the pictures.** Counts, section names and labels are the same in the words and the drawings.

`learning-tools-plugin.json` is the content file it was built from with `make_page.py build`; the pictures are in `learning-tools-plugin-pics/`. The page was written for the AjsLearningTools plan, so its subject is that plan. Use it for the form, not the content.
